Canonical code path

Controllers reach services through Fastify decorators on request.server, never a pool. Controllers hold no SQL; repositories hold all of it.

Actor classes

Customer

A person or their API key, over HTTP.

System

A background process. No human, no endpoint.

Operator

A privileged engineer on an authorized host.

Delivery state

Live

Implemented; this does not mean its process is running now.

Local only

Works locally; a gate remains before production.

Blocked

Waiting on evidence or authorization outside the code.
